Adaptive Dynamic Attribute and Rule (ADAR) Framework

University of Vaasa - Advanced AI

Team: Daniel Ebrahimzadeh, Haleh Adab, Amin Sarlak, Muhammad Abuzar

[cite: 1] "A Dynamic Fuzzy Rule and Attribute Management framework for FIS"

The Curse of Dimensionality

  • Neuro-Fuzzy Systems (NFS) struggle with high-dimensional datasets.
  • Traditional dimensionality reduction (e.g., PCA) decouples feature selection from inference logic.
  • Fixed rule structures either overfit complex regions or underfit local nuances.
  • The Goal: A framework that simultaneously learns feature relevance and dynamically adjusts its structural complexity [cite: 1].

The ADAR Methodology

  • K-Means Initialization: Data-driven anchoring of Gaussian membership functions.
  • Dual-Weighting: Differentiable importance scores ($\alpha$ for attributes, $\beta$ for rules).
  • Attribute Pruning: If $\alpha_{l,i} < \theta_{attr}$, the attribute is structurally bypassed.
  • Dynamic Growth: If validation loss plateaus, a new rule is explicitly anchored at the highest-error coordinate [cite: 1].

Implementation & Validation

  • Built entirely in PyTorch using auto-differentiation for dual-weight optimization.
  • Validated against a synthetic 27-feature dataset (Appliances Energy equivalent).
  • Ablation testing proved that dynamic rule growth outperforms static ANFIS architectures while maintaining interpretability (Overlap Index $I_{ov}$ and Position Index $I_{fsp}$).
